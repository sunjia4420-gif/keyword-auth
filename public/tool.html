📖 使用说明

三步流程

  • ①A 竞品词批量导入合并（多文件）：点「①B 竞品词批量导入合并」→「📁 选择文件 (多文件)」选 H10 Cerebro / AMZ123 等导出的多个 xlsx/csv/txt。系统按「关键词词组」列自动合并不去重，只标记重复（重复次数 / 是否重复 / 来源文件）；自然排名 ≤80 的出现次数记作「80重复次数」，其与重复次数的比值记作「80重复比」（若该词组只出现 1 次则比值记为 0）。弹窗确认列映射后可直接「解析词组」做年份归一（默认目标年 2026，可在卡片内修改），再进入第③步打标。
  • ①B 普通导入词组（单文件）：粘贴文本（每行一个）或导入单个 txt / xlsx / xls。Excel 会弹出列映射窗口，确认「关键词词组」列即可；搜索量、竞品数、CPR、广告排名、自然排名、重复 会自动识别中英文表头，未识别的按 0 处理。导入后按词组文本小写自动去重，保留第一条。（该路径无跨文件重复统计，「80重复比」列显示「—」表示不适用。）
  • ② 维护标签词库：左侧选分类，右侧编辑词条（每行一个），改完点「保存词条」。可增删分类、改名、改色、停用、写备注。
  • ③ 开始计算：点「开始计算」，分批处理并显示进度，可随时停止。计算完在下方表格查看结果，并可按标签 / 关键词 / 未打标筛选，最后导出 CSV。

三种匹配模式的区别与风险

  • 整词（推荐，默认）：把词组切分成单词后精确比对。dress 命中 summer dress，但不会命中 dresser。含空格的词条（如 plus size、v neck）按短语边界匹配。开启「单复数归一」后 dress 也能命中 dresses。
  • 子串（谨慎）：只要词组里出现该字符串就算命中。风险极高：red 会命中 shredded、hundred；尺码里的 s / m / l 会命中几乎所有英文词组。仅在需要覆盖拼写变体时使用（例如「禁用」分类里的 drawstring / draw string）。
  • 正则：每行一条正则表达式，忽略大小写。写错语法会在界面上标红提示并跳过该分类，不会让整个计算崩掉。示例：^plus\s?size、(long|short)\s+sleeve。

宽表 / 长表的用途

  • 宽表 CSV：每个标签分类独占一列，命中填 1、未命中填 0。丢进 Excel 直接做数据透视表 / 筛选 / 交叉统计，适合分析「哪些维度覆盖不足」。
  • 长表 CSV：标签用逗号拼在一列里，另附命中明细，适合快速人工浏览、贴回原有工作表。
  • 两种导出都在标准列之后附带重复统计列：重复次数、80重复次数、80重复比（导出原始小数，便于 Excel 计算）、来源文件（多文件用「|」分隔）、是否重复。
  • 两种导出都遵循当前筛选结果（筛了未打标就只导未打标），都带 UTF-8 BOM，Excel 打开不乱码。

关于「未打标词组」

未打标数量是衡量词库覆盖度最直接的指标。点顶部「未打标词组」按钮可只看这批孤儿词，把其中的高频词补进对应分类，再重新计算，覆盖率就会上升。

数据存储

标签词库、匹配选项、Excel 列映射记忆都存在浏览器 localStorage（kwTag_ 前缀），刷新不丢；换浏览器 / 清缓存会丢，重要词库请用「导出词库 JSON」或「保存配置」备份。
